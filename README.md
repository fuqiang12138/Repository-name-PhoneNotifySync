# PhoneNotifySync

小米15 → Windows 11 通知同步工具。

## 项目介绍

个人使用的手机通知同步软件，用于 Android 手机与 Windows 11 电脑之间的通知联动。

## 技术方向

### Android

- Kotlin
- Jetpack Compose
- HyperOS 兼容
- 本地通知处理
- 局域网通信

### Windows

- C#
- WinUI 3
- Windows 11 原生界面风格
- 通知显示组件

## 目录说明

- AndroidPhoneNotify：Android 客户端
- WindowsNotifyReceiver：Windows 客户端

## 说明

功能以仓库实际代码、编译结果和测试结果为准。
