# PhoneNotifySync

小米15 → Windows 11 通知同步工具。

目标：制作一个个人使用的 AirDrop 风格通知联动软件。

## 开发计划

### Android 客户端

- Kotlin
- Jetpack Compose
- AccessibilityService 通知捕获方案
- 小米 HyperOS 适配
- WebSocket 加密通信
- 设备配对

### Windows 客户端

- C# + WinUI 3
- Windows 11 Fluent Design
- 苹果风格通知卡片
- 毛玻璃效果
- 后台驻留
- 安装程序
