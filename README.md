# PhoneNotifySync

小米15 → Windows 11 通知同步工具。

目标：制作个人使用的 AirDrop 风格通知联动软件。

## 当前真实状态

### Android 客户端

已存在基础工程与原型代码：

- Kotlin Android 工程
- 基础 Activity
- 通知同步原型
- UDP 发送原型

待完善：

- 通知捕获方案优化
- 小米 HyperOS 适配
- WebSocket 通信
- 加密配对
- UI 重构
- APK 构建测试

### Windows 客户端

待开发：

- C# + WinUI 3 客户端
- Fluent Design UI
- 通知卡片
- 后台服务
- 安装程序
