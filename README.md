# PhoneNotifySync

小米15 → Windows 11 通知同步工具。

## 项目目标

制作个人使用的手机通知同步软件，实现 Android 手机与 Windows 11 电脑之间的通知联动。

## 技术方向

### Android

- Kotlin
- Jetpack Compose
- 小米 HyperOS 适配
- 本地通知处理
- 局域网通信

### Windows

- C#
- WinUI 3
- Windows 11 原生界面风格
- 通知显示组件
